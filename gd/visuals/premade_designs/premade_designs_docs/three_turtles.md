This module contains the class [`TurtleThree`](../three_turtles.py) which contains premade drawing functions which require a list of 3 turtles.

## Classes

### TurtleThree

This class contains premade drawing functions which require 3 turtles, all functions are directly accessible through [`Designs`](designs.md#designs).
