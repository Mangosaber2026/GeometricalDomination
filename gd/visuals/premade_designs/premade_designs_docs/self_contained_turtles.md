## Overview

This module contains the class [`TurtleSelfMade`](../self_contained_turtles.py) which contains premade drawing functions which require no turtles as an input as they internally create their own turtles.

## Classes

### TurtleSelfMade

This class contains functions which create their own turtles for their designs, all functions are accessible directly through [`Designs`](designs.md#designs).

### Functions

#### duo_triforce

This function draws and colors a triforce in a triforce with the corresponding colors.

Inspired by the [Triforce](https://www.nintendo.com/us/explore/characters/zelda/triforce/) from The Legend of Zelda series.
