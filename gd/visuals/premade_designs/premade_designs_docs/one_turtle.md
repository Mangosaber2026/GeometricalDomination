## Source code: One Turtle module

[View source code](https://github.com/Mangosaber2026/GeometricalDomination/blob/main/gd/visuals/premade_designs/one_turtle.py)

## Overview

This module contains the class [`TurtleOne`](../one_turtle.py) which contains premade drawing functions which need a list of one turtle.

## Classes

### TurtleOne

This class contains all drawings which require one turtle, all functions are accessible directly through [class `Designs`](designs.md#designs).

### Functions

#### hexaflower

This function draws rows and collumns of `hexaflower`s using [`Shapes.hexaflower_tri`](https://github.com/Mangosaber2026/GeometricalDomination/blob/main/gd/visuals/premade_shapes/shapes.py).
