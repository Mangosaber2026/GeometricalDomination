## Overview

This module contains the class [`TurtleTwo`](../two_turtles.py) which contains premade drawing functions which require a list of 2 turtles.

## Classes

### TurtleTwo

This class contains premade drawing functions which require a list of 2 turtles, all functions are available through [`Designs`](designs.md#designs).
