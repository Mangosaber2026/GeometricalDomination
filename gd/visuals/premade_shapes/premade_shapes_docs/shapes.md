# Shapes Module

## Source code: Shapes

## Overview

This module contains the [`Shapes`](../shapes.py) which contains reusable shapes for the rest of the GeometricalDomination software.

## Classes

### Shapes

This class contains predefined shapes which are used all throughout the GeometricalDomination software.
